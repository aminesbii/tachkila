# Agent guide — Tachkila

Tachkila is a native auction-draft app for one phone. Expo SDK 58 + React Native
0.88 + Expo Router + TypeScript. The old Next.js web app lives on `legacy/web` and
must not be resurrected.

## Golden rules

1. **The engine is pure.** Everything under `src/engine` is a function from state to
   state. No React, no storage, no `Date.now()` inside rule functions. Add rules
   there and cover them in `tests/`.
2. **All persistence goes through `src/storage/room-repository.ts`.** Do not touch
   AsyncStorage directly outside `src/storage/async-storage.ts`.
3. **One host, one phone.** There is no server, no auth and no network at runtime.
   Keep it that way unless the product explicitly adds online play.
4. **Dark only.** Colours, spacing, radii and typography come from `src/theme`.
   Never hard-code a hex value in a component when a theme token fits.
5. **Bid entry uses `BidPad`.** Never focus a `TextInput` for numeric bids.

## Commands

```bash
npm run typecheck   # must pass
npm run lint        # must pass
npm test            # 43 Vitest tests
npm run doctor      # expo-doctor, 20 checks
npm run android     # debug build on emulator/device
npm run start:tunnel  # Metro over a tunnel, for a physical iPhone
npm run icons       # regenerate assets from scripts/generate-icons.mjs
```

## Layout shorthand

- `src/app` — routes. `_layout.tsx` wires providers; `game/[code].tsx` is the main
  screen with lobby / auction / results modes.
- `src/components/ui` — generic kit (`Button`, `Card`, `Field`, `BottomSheet`,
  `Toast`, `Screen`, …).
- `src/components/game` — auction-specific pieces (`PlayerCard`, `Pitch`,
  `TeamCarousel`, `AssignSheet`, `SaleOverlay`, `BidPad`, `Standings`, …).
- `src/components/setup` — new-game wizard pieces shared with the edit sheet.
- `src/hooks` — `useRoom` (game state + actions), `useGames` (home list),
  `useSettings` (haptics).
- `src/lib` — pure presentation helpers (`game-view`, `display`, `setup`,
  `feedback`).

## Conventions

- TypeScript strict; import through the `@/` alias.
- Prefer small pure helpers in `src/lib` over inline logic in JSX.
- React Compiler lint rules are on: no ref reads during render, no synchronous
  `setState` inside effects. Animate through `useState(() => new Animated.Value())`.
- State that must reset when a sheet opens is reset by remounting it with a `key`
  from the parent instead of an effect.
- Every interactive element needs `accessibilityRole` and a label.
- Copy is English only, sentence case, no exclamation marks in body text.

## Data model notes

- `RoomDoc.schemaVersion` is `2`. `updatedAt` / `createdAt` are epoch milliseconds.
- `ROOM_SCHEMA_VERSION` must be bumped whenever `RoomDoc` changes, and
  `parseDoc` in the repository must migrate older documents.
- Undo snapshots live beside the room, not inside it, so a future sync layer can
  replay actions without shipping the stack.

## Android notes

- `android/` and `ios/` are generated by `expo prebuild` and are gitignored.
- Release signing uses `MYAPP_UPLOAD_*` Gradle properties (see README).
- Node must be `^22.13.0`+ for SDK 58; older 22.x prints a warning but works.
- The project lives in OneDrive: pause sync while Gradle/Metro runs to avoid file
  locks.

## iOS notes

- No Mac here: `npm run ios` and `expo prebuild --platform ios` do nothing useful on
  Windows (prebuild skips native generation).
- To run on a real iPhone, use Expo Go (`npm run start:tunnel`) or build the unsigned
  `.ipa` with the `iOS unsigned IPA` workflow, then sign it with Sideloadly and a free
  Apple ID (7-day signature). See README "Run it on your iPhone".
- `npm run build:ios-ipa` works on macOS only; `eas build -p ios` for a device needs
  the paid Apple Developer Program.

## Definition of done

`npm run typecheck`, `npm run lint`, `npm test` and `npm run doctor` all pass, the
app launches on `Pixel_9`, and a full game can be created, played to results, undone
and reopened after a restart.
